### RC-001-REV-001 - Unauthenticated command execution through deployment webhook
- Severity: **high**
- Confidence: **high**
- Binding (Function/Subfunction/Flow): `BF-011` / `SF-026` / `CF-020` (Not mapped / Not mapped / Not mapped)
- Entry Point: POST /hook_deploy is mapped by routes/web.php to WebHook::deploy.
- Sensitive Point / Risk Landing Zone: The controller runs shell_exec for a log append and for cd into the application path followed by git pull.
- Missing or Failed Control: Completely missing active server-side authentication before command execution
- Evidence and Data Flow: The evidence closes source, transit, sink, and missing control: a public web route reaches a controller where authentication is commented out and shell_exec runs deployment commands. Source/Transit/Sink files: app/Http/Controllers/WebHook.php, routes/web.php
- Why It Holds: The evidence closes source, transit, sink, and missing control: a public web route reaches a controller where authentication is commented out and shell_exec runs deployment commands.
- Business Impact: Any caller that can reach the route can trigger application-level shell commands that run git pull from the application base path.
- Remediation Recommendation: Restrict endpoint access, enforce strong request authentication/signature verification, and remove direct shell execution from request handlers.
